# S.O Boards — Susan Orozco

Landing estática en español para diseño de circuitos, placas PCB y firmware.
HTML, CSS y JavaScript puro. No requiere instalar dependencias ni compilar.

## Archivos

- `index.html`: estructura y textos.
- `assets/styles.css`: diseño y adaptación a celulares.
- `assets/script.js`: descarga del resumen de consulta.
- `assets/logo.png`: logo original.
- `.nojekyll`: permite servir el sitio estático directamente.

## Ver en tu computadora

Abrí `index.html` en tu navegador. También podés usar Live Server de VS Code.

## Subir a GitHub

1. Creá un repositorio, por ejemplo `so-boards`.
2. Descomprimí este ZIP.
3. Subí el contenido de la carpeta `so-boards` al repositorio. El archivo `index.html` debe quedar en la raíz, junto a `assets` y este README.
4. Confirmá los archivos en la rama `main`.

## Publicar con GitHub Pages

En la configuración del repositorio, abrí Pages y elegí publicar desde la rama `main`, carpeta raíz (`/`). Guardá y esperá a que GitHub indique la dirección publicada. La disponibilidad depende del plan y la visibilidad del repositorio.

Las rutas de los archivos son relativas, por lo que sirven también bajo una subcarpeta de GitHub Pages.
